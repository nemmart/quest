## Part 1 — plan gate

1. **The hook table artifact** `quest.strhooks` (pushmap tradition,
   provenance header with the census sha): per `p@b` block — block
   address, arena row id, the FIRST WMSP pc (bind), the group's last
   WMSP pc (for the pushed temp's address; see 3), all WMSP pcs with
   their claim-size expression (`⌈(len+k)/4⌉` — evaluated at the hook
   from the master's ac, not pre-computed), the STASP pc(s). 19 rows,
   57 WMSP, 19 STASP. Loader: refuses a duplicate pc, a pc not in the
   listing, a block without exactly one first-WMSP. Generated by a small
   Python tool from the P31 census (`tools/strhooks.py`; runtime line).
2. **Master-side hooks** (the master runs original bytes; hooks are per-pc,
   the mechanism QUEST_INJECT/POKE and the terminal table already use):
   - first-WMSP pc → `arena_bind(row, master_wfp, master_addr)` where
     `master_addr` is the address the master will PUSH for this group.
     Plan-gate choice (§6.3): record it when the group's LAST WMSP fires
     (`wsp_before + 2`), or compute from the first claim's `wsp_before`
     and the census sizes. Recommend, with the evidence (the last claim
     is the `+5/+6` one with room for the length word — check all 19).
   - every WMSP pc → `ClaimDelta::claim(wfp, ac)`; every STASP pc →
     `ClaimDelta::release(wfp, old_wsp, new_wsp)`.
   - WRTN (the emulator's instruction, hook by opcode when the popped
     frame's wfp owns rows) → `arena_unmap_frame(wfp)` +
     `ClaimDelta::frame_exit(wfp)`.
   - ON-system pop → the same two, for every frame at or above the
     restored one. WHERE: `I.GOTO` is native (frames.cpp:261) and is the
     non-local exit of record; the Mapper's unwind-cut mutation
     (Mapper.md §3 item 3, `area_unwind_to`) already fires there — hang
     the arena unmap on the same event. Confirm from the source that
     DERR/DEF?ON/?FATAL paths are TERMINAL (TerminalDetach.md) and so
     never need it; any other frame-restoring path you find is a
     FINDING.
3. **compare_pair wiring**, behind `QUEST_STRINGS_CHECK=1`: the wsp
   compare becomes `master_wsp − clone_wsp == ClaimDelta::delta(wfp)`;
   the AC compares already go through `equivalent()`, which P30 taught
   about arena rows — state what, if anything, changes in the call
   (nothing, ideally). An unmapped-row hit is a MISMATCH with a message
   naming the row and block. Flag off: byte-identical behaviour to
   today (no hooks armed, no delta term).
4. **F2-b**: in compare_pair, an assert-detached clone paired with a
   master arriving at a kind-2 terminal → TERMINAL-ABORT (one final
   verified pair: the clone's assert pc and the master's terminal pc
   both printed), instead of the detached early-out at :151. State the
   exact ordering change and why nothing else can reach it.
5. **The readout fix**: `w-2`/`w-4`; prove it with the same `derr-emu`
   poke P27 used (expected `00000011 7015C48E`).
6. **Test plan**: (a) unit: a scratch Machine pair driving the hooks by
